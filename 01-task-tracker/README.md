# Task Tracker CLI application using nodejs

## This app allows a user to add, list, update & delete tasks from command line

## built using nodejs

<https://roadmap.sh/projects/task-tracker>

## How to use

```bash
## Adding a new task

add "Buy groceries"

## Updating and deleting tasks

update 1 "Buy groceries and cook dinner"
delete 1

## Marking a task as in progress or done

mark-in-progress 1
mark-done 1

## Listing all tasks

task-cli> list

## Listing tasks by status

list done
list todo
list in-progress
```
